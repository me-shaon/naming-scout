# Case: newsletter

Tests the lightest check set, and format as a naming constraint.

**Brief**

> A weekly newsletter about what actually happened in a startup that week, written by
> founders, no advice. Name it.

**Must**

- Check domain, socials and search presence. Nothing else.
- Treat the format as a constraint: the name is read in an inbox subject line.
- Grade searchability. A newsletter that cannot be found by name has no growth channel.

**Fails if**

- npm, PyPI or GitHub appear anywhere in the run.
- A name is recommended that cannot be spelled after hearing it once.
