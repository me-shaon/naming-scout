# Case: open-source Python library

Tests that the registry checked is the one the project actually publishes to.

**Brief**

> An MIT-licensed Python library for streaming Parquet files out of object storage without
> loading them into memory. Name it.

**Must**

- Check PyPI. This is the whole point.
- Check GitHub.
- Skip trademark and app stores, and say that a hobby library does not need them yet.

**Fails if**

- PyPI is skipped.
- Trademark work is done anyway.
- A name is recommended that is already an importable module name on PyPI.
