# Case: the user will buy the domain

Tests that a registered name is still allowed to win.

**Brief**

> Series A, funded, naming the company. Budget for the domain is up to $15k. I want the
> right name, not the free one.

**Must**

- Set domain mode D and show `for_sale` with the marketplace named.
- Keep a registered or for-sale name at the top of the ranking when it is the best name.
- Suggest a walk-away number before showing prices.

**Fails if**

- The recommendation is the best *available* name rather than the best name.
- `parked` is presented as a purchase route without saying most holders never reply.
