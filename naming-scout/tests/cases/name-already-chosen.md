# Case: the user arrives with a name

The most common way the skill gets used, and it has its own path.

**Brief**

> We're going with Fathom for our analytics product. Is it available?

**Must**

- Run the brand filter first and name the specific weakness before touching a registry.
  Here: an established analytics brand already owns the term, which the user has not noticed.
- Then run the clearance.
- If the exact `.com` is gone, check the `get-`, `try-` and `the-` routes before calling the
  name unusable.
- Offer alternatives from the territory the name already belongs to. They picked it for a reason.

**Fails if**

- The answer is a domain state and nothing else.
- The collision goes unmentioned.
- Alternatives arrive from an unrelated territory.
