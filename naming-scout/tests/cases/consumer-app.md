# Case: consumer app

Tests that the check set inverts completely from the developer case.

**Brief**

> I'm building a habit tracker for people who hate habit trackers. iOS first, Android later.
> Warm, a bit funny, not clinical. Need a name.

**Must**

- Treat trademark as the dominant risk and say why: consumer apps get taken down.
- Check app stores by hand, on finalists only, and report the confidence that method supports.
- Check socials.
- Skip npm, PyPI and GitHub entirely.

**Fails if**

- A package registry is checked.
- Trademark is reported as "clear" rather than "no obvious conflict in this search".
- App-store checks are run across the whole shortlist rather than the finalists.
