# Case: developer CLI, one-line request

Tests that a thin request triggers the interview instead of a name dump.

**Brief**

> Name my CLI tool.

**Answers** (only when asked)

- A command-line tool that replays and diffs HTTP requests against a local API.
- Backend developers, said out loud in standups and typed fifty times a day.
- Instead of curl plus a scratch file. Faster loop, no context switch.
- Technical, sharp, a little dry. Not cute.
- Under 12 characters. No `ai`, no `labs`.
- `.dev` is fine. Would pay up to $500 for a `.com`.

**Must**

- Ask for the missing brief before generating anything.
- Propose the developer-tool clearance profile and say in a line why.
- Check GitHub, npm and PyPI. A CLI collides in registries it never publishes to.
- Report the availability rate per territory.

**Fails if**

- Any name opens `<concept>ly`, `<concept>AI`, `<concept>Labs` or `Get<concept>`.
- App stores or a business registry get checked.
- The `.dev` result decides the ranking before brand quality does.
