# Discovery

RDAP endpoints vary by TLD registry with inconsistent error handling. `.io`, `.me`, `.sh`, `.tv` missing from IANA bootstrap but verifiable via direct registry endpoints. `rdap.org` returns false 404s making it unsafe as fallback. Afternic nameservers (`ns1.afternic.com`, `ns01.trademarkarea.com`) reliably signal aftermarket/for-sale domains vs. parked.
