# Discovery

`npx skills add` installs skills from git repos, not npm. Vercel's `skills` CLI discovers skill repos by looking for SKILL.md files and scans well-known paths like `.claude/skills`, `skills/`, `.agents/skills`. The repo layout is discovered as-is with no build step required.
